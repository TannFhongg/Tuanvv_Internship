# Core Memory

Các ví dụ trong nhóm này tập trung vào RAII, smart pointers, vòng đời object,
copy/move semantics và cấp phát bộ nhớ an toàn.

- `examples/core_memory/smart_pointer/`: ownership với `std::unique_ptr` và
  `std::shared_ptr`.
- `examples/core_memory/modern_cpp/`: special member functions, buffer và
  factory dùng custom deleter.
